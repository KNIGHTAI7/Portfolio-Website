## ✨ Overview

A fully custom, single-file portfolio website built with pure **HTML, CSS & JavaScript** — no frameworks, no dependencies. Designed with a **Futuristic Cyber-Minimalism** aesthetic featuring deep black backgrounds, neon gradients, and smooth animations to showcase AI/ML projects, certifications, and skills.

## 🪐 Features

- **Animated Solar System** — skill-named planets (Python, SQL, NLP, Deep Learn, Power BI, Gen AI) orbiting a glowing sun with trail effects and orbit path rings
- **Custom Cursor** — neon cyan dot with magenta trailing ring
- **Stats Ticker** — scrolling marquee of key achievements
- **Project Cards** — 6 AI/ML projects with Explore, GitHub & View buttons
- **Project Detail Pages** — dedicated sub-page for each project with full description, tech stack, and features
- **Certificate Viewer** — click-to-open modal rendering certificates visually (Generative AI Mastermind · AI Fluency)
- **Power BI Dashboard Modal** — embedded CarDekho dashboard screenshots with KPI cards, brand charts, and full-screen image lightbox
- **About & Education** — timeline-style education cards with contact info
- **Particle Background** — 70 floating neon particles across the entire site
- **Loading Screen** — animated progress bar on page load
- **Fully Responsive** — works on mobile and desktop
