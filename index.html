Text Summarizer 2.0

Abstractive Multi-Domain NLP Summarization Engine
OVERVIEW

An enhanced abstractive text summarization model built with fine-tuned transformer architectures and advanced prompt engineering techniques. The system generates human-quality summaries across diverse domains including news articles, research papers, technical documentation, and more — with significantly reduced hallucination compared to baseline models.

KEY FEATURES
◆
Fine-tuned transformer model for abstractive (not extractive) summarization — generates new, coherent text rather than copying sentences.

Advanced prompt engineering techniques to guide the model's output quality and minimize hallucination artifacts.
◆
Multi-domain support: works across news, academic, legal, technical, and conversational text types.
◆
Evaluation with ROUGE metrics to benchmark performance against previous version and baseline models.

PROJECT_02 // COMPUTER VISION + LLM

OpticEats

AI-Powered Food Ingredient Analyser
OVERVIEW

OpticEats is an intelligent food label analysis system that combines Optical Character Recognition (OCR) with Large Language Model reasoning. Simply photograph any food label and receive an instant, comprehensive health breakdown — no manual reading required.

KEY FEATURES
◆
OCR pipeline extracts ingredient text from food label photographs with high accuracy across varied lighting and label formats.

Nutritional risk scoring: flags high-sugar, high-sodium, artificial additives, and E-number concerns.

Clean Streamlit UI for easy label upload and instant readable health report generation.

PROJECT_03 // DEEP LEARNING

Captify AI

CNN + LSTM Image Captioning System
OVERVIEW

Captify AI is an image captioning system built on a classic encoder-decoder deep learning architecture. A Convolutional Neural Network encodes rich visual features from images, which are then decoded by an LSTM network into grammatically correct, contextually meaningful captions.

KEY FEATURES
◆
CNN encoder (based on VGG/ResNet) extracts high-level visual feature vectors from input images.
◆
LSTM decoder generates word-by-word captions conditioned on visual context, with beam search for quality.
◆
Trained on diverse image categories — objects, scenes, people, actions — producing coherent descriptions.
◆
Interactive Streamlit interface to upload any image and generate real-time captions.
TECH STACK
PythonCNN LSTMDeep Learning TensorFlow/KerasStreamlit

PROJECT_04 // REAL-TIME AI

Indian Sign Language Translator

Real-Time Gesture Recognition & Text Output
OVERVIEW

A real-time Indian Sign Language (ISL) recognition system that bridges communication between the deaf/hard-of-hearing community and the general public. The system uses a custom-built dataset and CNN classifier to recognize ISL hand gestures from live camera feed and translate them to text output instantly.

KEY FEATURES
◆
Custom ISL gesture dataset built specifically for Indian Sign Language — covering alphabets and common phrases.
◆
CNN classifier trained on the custom dataset achieves high accuracy across varied lighting and hand positions.
◆
Real-time OpenCV pipeline: live camera capture → hand detection → gesture classification → text display.
◆
End-to-end pipeline with minimal latency, designed for practical real-world use.
TECH STACK
PythonDeep Learning OpenCVCNN Custom DatasetReal-time Inference
⚠ DEPLOYMENT NOTE

This project requires real-time webcam access and local compute — it cannot be deployed on Streamlit Cloud due to webcam API limitations. To run locally:

  • Clone the repository from GitHub
  • Install dependencies: pip install -r requirements.txt
  • Run: python app.py
  • Allow webcam access when prompted
  • Show ISL gestures in front of camera for live translation

PROJECT_05 // NLP PIPELINE

ClinIQ

Clinical NLP Intelligence & Medical Report Analysis
OVERVIEW

ClinIQ is an end-to-end clinical NLP pipeline that intelligently processes medical reports. It automatically summarizes lengthy clinical documents, extracts key medical entities, maps findings to standardized ICD-10 codes, and generates structured clinical notes — significantly reducing the documentation burden on healthcare professionals.

KEY FEATURES
◆
Automated medical report summarization — condenses complex clinical documents to key findings.
◆
Named Entity Recognition (NER) extracts diagnoses, medications, symptoms, lab values, and procedures.
◆
ICD-10 code mapping — automatically assigns standardized international disease classification codes.
◆
Structured clinical note generation in standard SOAP (Subjective, Objective, Assessment, Plan) format.

PROJECT_06 // BUSINESS INTELLIGENCE

AutoIntelligence

CarDekho Market Analytics Dashboard — Power BI
OVERVIEW

A comprehensive Power BI dashboard and strategic analysis of India's pre-owned vehicle market using CarDekho dataset of 2,059 vehicles. Transforms raw listing data into actionable business intelligence — from depreciation curves to inventory optimization recommendations.

KEY INSIGHTS DISCOVERED
◆
15–20% ownership premium: First-owner vehicles command significantly higher prices vs second/third-owner equivalents.
◆
Sweet spot inventory: 4–6 year old first-owner SUVs offer optimal depreciation vs desirability balance for resellers.
◆
Market bifurcation: Volume segment (Maruti, Tata) vs luxury segment (Ferrari ₹35M, Rolls-Royce) with distinct feature patterns.
◆
Transmission premium: Automatic transmission correlates strongly with higher price points, especially above ₹15 Lakhs.
